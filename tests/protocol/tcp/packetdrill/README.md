# The packetdrill TCP corpus as protocol tests

Each `.test` file in this folder is a wrapper for one script of the packetdrill TCP corpus
that inet-gpl vendors: the Linux kernel selftests (`kernel/`) and the upstream packetdrill
tests (`gtests/`). A wrapper sits in the folder of its corpus and is named for its script id,
with `/` written as `__`: `gtests:fastopen/server/opt34/basic-rw` is
`gtests/fastopen__server__opt34__basic-rw.test`.
The names are unique across `tests/protocol`, because INET's test runner extracts every test
into `work/<file name>`. A wrapper runs the
script in INET through `run`, which hands it to leg I of the inet-gpl TCP oracle
(`tests/oracle/oracle.py inet-one`), and it passes when the output ends with
`PACKETDRILL <corpus:script_id>: PASS`.

A pass is **Linux equivalence**, not conformance to an RFC: Linux passes every one of these
scripts (the leg L goldens, Linux 7.1.3), and a pass says that INET does the same.

The scripts, the packetdrill parser and the packet comparison are GPL licensed and stay in
inet-gpl. These files hold no line of a script. Without inet-gpl every wrapper is skipped:

```sh
cd <inet> && source setenv -q && cd <inet-gpl> && source setenv -q
inet_run_protocol_tests --filter packetdrill
```

The wrappers and this file are generated by `oracle.py gen-wrappers` in inet-gpl, and
`oracle.py gen-wrappers --check` shows them out of date. Do not edit them by hand.
