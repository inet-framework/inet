# IEEE 802.11 capability and BSS state: rebase evidence

> **Status:** verified · **Date:** 2026-11-15

The rebase preserves the capability and BSS changes on `origin/master` at `91219b0fa7`. It also preserves master's rate state, peer cleanup, response selection, and checks before frame transmission. The original branch remains available as `backup/feat-coap-before-rebase-20261115`.

## Conflict decisions

The user selected both notification signals. The MIB stages BSS, capability, and rate changes. Management completes its state, timers, and transactions before it calls `publishStateChange()`. Changes to rates, HT capabilities, channel operation, or BSS availability trigger `rateStateChanged`. A change to association status alone triggers only `bssStateChanged`. A rate-only change preserves the immutable capability result.

For example, a successful replacement removes the old association and installs the new association within one management action. Observers see the complete new association. They do not receive a separate notification for the temporary empty state. The tests check this boundary. The MIB rejects a mutation from an observer during either notification.

The user also selected capability retention when an HT operation is unusable. For example, an associated AP can advertise a valid Basic HT-MCS Set that exceeds the STA's capabilities. The STA retains its capability result but blocks HT transmission. A later usable operation restores HT eligibility. A malformed advertisement still follows the existing rejection path.

The rebase also preserves master's cleanup of Block Ack and QoS state after association loss or replacement. Rate selection receives the current operation separately from the cached capabilities. HCF checks a retained mode against that current state before it submits the frame.

An HT receiver can have a known channel in a legacy BSS without an HT operation. Rx now checks `hasHtOperation()` before it reads RIFS permission. The previous library fails the new case with `No committed IEEE 802.11 HT operation is available`. The final interval fixture passes its 52 selected runs with the corrected guard.

## Test migration

The tests now use MIB queries and management methods instead of writable fields. Tests that change MIB state directly publish the completed change explicitly. Tests for callback mutation now check rejection and unchanged state. The response tests retain their checks for both directions and both selectors.

The VHT capability test now uses production MAC preparation with antenna counts 1, 2, 3, 4, and 8. Its location is `tests/module/Ieee80211VhtHtCapabilities_1.test`. The old unit test called the capability assembly method that the branch removes from the MIB.

The tests for an invalid retained catalog now supply that mismatch through a test subclass. The local interval test calls the explicit history reset method. These tests do not establish support for runtime reconfiguration of the complete interface catalog.

The offline external-interface fixture compiles the production interface and TAP components into its executable when the optional emulation feature is disabled. It deletes the TAP endpoint before initialization. This preserves its configuration checks without a host OS device or a change to enabled INET features.

The installed runner rejects the unused `coverage.report` entry in `inet.opp`. A temporary copy omits that entry and uses the absolute checkout path. Fingerprint discovery uses a second copy with `ini_file_folders` limited to `examples/adhoc/qos`. These copies preserve simulation parameters, NED paths, and recorded baselines.

The following script recreates those temporary configurations from the active checkout.

```sh
python3 - <<'PYCONFIG'
from pathlib import Path
text = Path("inet.opp").read_text()
text = text.replace('root_folder="."', f'root_folder={str(Path.cwd())!r}')
lines = [line for line in text.splitlines() if not line.lstrip().startswith('"coverage":')]
Path("/tmp/inet-coap-rebase-compatible.opp").write_text("\n".join(lines) + "\n")
lines = ['    ini_file_folders=["examples/adhoc/qos"],' if line.strip().startswith("ini_file_folders=") else line for line in lines]
Path("/tmp/inet-coap-rebase-fingerprint.opp").write_text("\n".join(lines) + "\n")
PYCONFIG
```
