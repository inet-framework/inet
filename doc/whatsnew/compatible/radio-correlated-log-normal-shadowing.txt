Correlated log-normal shadowing

LogNormalShadowing has a new correlationDistance parameter. By default (NaN) every path loss computation draws a new shadowing value, as before. With a distance, the value is kept per pair of radios, the same in both directions, and drawn again only when either radio has moved farther than that distance from where it was when the value was drawn, which is how shadowing behaves physically. The value is resolved once per reception, so with DimensionalMediumAnalogModel the whole band of a reception has the same shadowing. The values of a radio's links are dropped when the radio is removed from the medium.
