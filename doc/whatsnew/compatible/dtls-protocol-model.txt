DTLS 1.3 association model

Adds a UDP-backed DTLS 1.3 handshake model with external PSK or certificate profiles, cookie validation, key-share retry, initial client authentication and independent peer associations. It uses ordinary host application slots and configurable processing costs. Cryptographic operations follow IPsec's retained-chunk abstraction. This checkpoint requires loss-free handshake traffic; loss recovery, key updates and graceful closure are not provided.
