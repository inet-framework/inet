DTLS 1.3 association model

Adds a UDP-backed DTLS 1.3 model with external PSK or certificate profiles, cookie validation, key-share retry, initial client authentication and independent peer associations. Fragmentation, selective acknowledgements and bounded retransmission recover handshake traffic over lossy UDP. Protected application datagrams preserve UDP boundaries and reordering, with replay filtering and bounded record sizes. Key updates change directional protection epochs with independent ACK recovery and bounded application holding. It uses ordinary host application slots and configurable processing costs. Cryptographic operations follow IPsec's retained-chunk abstraction. Graceful closure is not provided at this checkpoint.
