DTLS 1.3 simulation model

Adds a UDP-backed DTLS 1.3 model with external PSK or certificate profiles, cookie validation, key-share retry, initial client authentication and independent peer associations. Fragmentation, selective acknowledgements and bounded retransmission recover handshake traffic over lossy UDP. Protected application datagrams preserve UDP boundaries and reordering, with replay filtering and bounded record sizes. Key updates change directional protection epochs with independent ACK recovery and bounded application holding. Closure and lifecycle operations release one peer without disrupting others on the shared socket. It uses ordinary host application slots and configurable processing costs. Cryptographic operations follow IPsec's retained-chunk abstraction.
