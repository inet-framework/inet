Serializers and dissectors read back what they write

Many serializers now read back a captured packet byte for byte, so PCAP recording, PCAP replay and emulation give correct packets. ICMPv6 Packet Too Big and Parameter Problem messages serialize, and Parameter Problem has the field pointer. IGMP has the RGMP Hello message. BGP keeps the UPDATE path attributes of unmodeled types as BgpUpdatePathAttributesUnknown, and a wrong length no longer hangs its deserializer. PIM serializes a Graft without content, the reserved field of Register and the R and T bits. The cookies and keygen tokens of the Mobility Header are 64 bits, with the new fields homeNonceIndex and careOfNonceIndex. Ipv6RoutingHeader has the fields lastEntry, flags and tag of SRv6. SCTP keeps its state cookie for captures with absolute time (the new field creationTimeRaw), and it reads back the parameters and chunks that it lost before, for example NR-SACK, ASCONF and the Forward-TSN-Supported parameter. RTP, RTCP, DHCP and TCP serializers repair their round trips too.

The link layer serializers follow the standards more closely. Ethernet reads all four kinds of the start-of-mPacket delimiter, and dissects the MAC control (PAUSE) frame. LLC writes the DSAP and the SSAP in the standard order, MACsec checks the EtherType 0x88E5 that it writes, and the acknowledgement of CsmaCaMac has its own type code 2. These two changes change the bytes on the wire. Each MRP frame now carries the address of the bridge; before, it carried an all-zero source address. With real addresses, the election of an automatic manager works, and an automatic manager sends TestMgrNack, so the results of the MRA configurations change. MRP LinkUp and LinkDown carry the port role, and CFM dissects the Continuity Check Message and models the MEG ID as a MAID.

There are new protocol dissectors: AODV (with UDP port 654), BGP (with TCP port 179), the Mobility Header, MLD (from ICMPv6), DHCP (with UDP ports 67 and 68), RTP and RTCP. The new protocols come at the end of the protocol list, so the existing protocol ids and fingerprints do not move.

The packet data fingerprints (~tND) of the affected simulations change. The new serializer tests check these round trips.
