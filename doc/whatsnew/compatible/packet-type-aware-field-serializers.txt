Type-aware field chunk serializers

FieldsChunkSerializer gained two protected hooks, serializeFields() and deserializeFields(). The deserializeFields() hook receives the concrete chunk type that was requested from ChunkSerializerRegistry, so a serializer that is registered for several chunk types can build the exact requested type. The old hooks, serialize(stream, chunk) and deserialize(stream), are deprecated but still work: they are no longer pure virtual, and the new hooks call them by default. Serializers written against an earlier INET version need no source change. See the migration guide for the new signatures.
