The interface metric of Ipv6NetworkConfigurator sets the metric of its on-link routes

The metric attribute of an <interface> element in the Ipv6NetworkConfigurator configuration was read and then ignored, although the documentation lists it. It now sets the metric of the on-link (direct) routes that the configurator adds through that interface, as the interface metric of Ipv4NetworkConfigurator sets the metric of the directly connected route. Routes via a next hop, the link-local fe80::/10 route of each interface, and on-link routes learned from Router Advertisements are not affected. A configuration that sets the attribute on an Internet Protocol version 6 (IPv6) interface now gets the metric it sets on those routes, and the metric chooses between two routes of the same prefix length and administrative distance.
