Static entries of the MAC forwarding table do not age out and learning does not overwrite them

A static unicast entry of MacForwardingTable, from the forwardingTable parameter, a MacForwardingTableConfigurator, a StreamRedundancyConfigurator or the forwardingTableFile parameter, did not carry the marker of a static entry. It aged out at 119 s (120 s for a file entry) with the default agingTime of 120 s, after which the switch flooded its destination; a switch without a learner, such as a TsnSwitch with incoming or outgoing streams, kept flooding. A learning switch instead overwrote the entry from the first frame of that address, so the configured port held only while the station was silent. Static entries now stay for the whole simulation and learning does not overwrite them, as the user guide states. Learned entries still age out. A station that is moved to another port of a switch that has a static entry for it is now reached through the configured port until the entry is changed.
