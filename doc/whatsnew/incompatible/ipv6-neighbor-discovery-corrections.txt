IPv6 Neighbor Discovery corrections

A datagram whose transport gives no hop limit now leaves with the CurHopLimit of its outgoing interface (RFC 4861 section 6.3.2): 64 by default, or the Cur Hop Limit of the last Router Advertisement on that interface. Before, every such datagram left with the constant 30, and the value of the router was stored but not used. The hop limit field of most IPv6 datagrams changes, so the fingerprints that include packet data change.

Two defaults of Ipv6RoutingTable follow RFC 4861 section 6.2.1: advCurHopLimit is 64 (it was 30), and advLinkMtu is 0 (it was 1280). A Router Advertisement now carries an MTU option only when advLinkMtu is not 0; before, it always carried one, also with the value 0. Set advLinkMtu to keep the MTU option. Every Router Advertisement with the defaults is 8 octets shorter, so simulations with routers of IPv6 change.
