An unrecognized IPv6 Routing header type is reported, not thrown

Ipv6::processExtensionHeaders threw a cRuntimeError when a received Routing
header had a non-zero Segments Left and a Routing Type that no module had
registered. Only Mobile IPv6 registers one, type 2, so a single packet with any
other type, such as a Segment Routing over IPv6 (SRv6) header of type 4 or a
deprecated type 0 header, stopped the simulation at its destination.

RFC 8200 section 4.4 requires the node to discard the packet and send an
ICMPv6 Parameter Problem message, code 0, whose Pointer field names the
Routing Type. Ipv6 does that now.

Simulations that never received such a packet produce the same results.
