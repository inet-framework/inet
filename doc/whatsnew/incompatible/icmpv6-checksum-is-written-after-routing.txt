The ICMPv6 checksum is written after routing

In "computed" checksum mode, the Internet Control Message Protocol for IPv6
(ICMPv6) checksum is now written by a post-routing hook that the Icmpv6
module registers on the Ipv6 module, instead of where the message is
built. The new networkProtocolModule parameter of Icmpv6 names that
module. Icmpv6::insertChecksum() in "computed" mode now only zeroes the
field. Code outside INET that sends an ICMPv6 message without passing it
through Ipv6 must compute the checksum itself; see the migration guide.
