A weighted round-robin classifier moves its round only for a packet

WrrClassifier moved its round forward in each query about a packet, for example when a module asked canPushPacket() before it pushed the packet. The packets then went to other consumers than the weights state. The classifier now moves its round only when a packet goes through. This can change the results of simulations in which a module asks a WrrClassifier about a packet before it pushes the packet.
