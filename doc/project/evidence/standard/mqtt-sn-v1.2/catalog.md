The specification inherits MQTT behavior where it supplies no replacement. This model's upstream wire version is MQTT 3.1.1: its packet identifiers, QoS 1/2 state, retained publications, wildcard matching and session recovery use the existing MQTT model. MQTT-SN changes the message layouts, introduces errors and periodic datagram retries, extends persistence to Will data and adds sleeping/discovery. In particular MQTT-SN SUBSCRIBE has a retry DUP flag whereas MQTT 3.1.1 SUBSCRIBE has fixed header flags; MQTT-SN PUBREL has no flag octet. MQTT 3.1.1 Session Present has no MQTT-SN counterpart. Do not copy those upstream wire details into MQTT-SN.

Interpret section 6.12's contradictory CleanSession sentence using section 6.3's explicit four-case matrix. The model chooses the shorter-duration tolerance branch at exactly 60s, and zero-duration sleep is acknowledged then expires without an added processing delay. These are documented interpretations, not additional normative text. Section 4.1's complete end-to-end gateway transparency, section 5.5 forwarder encapsulation and section 7.4 native ZigBee behavior are outside the selected model. The remaining local transport and failure-policy choices are in the plan.
