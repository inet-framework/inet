# MQTT standards

> **Kind:** reference · **Status:** current · **Seal:** none · **Owns:** — · **Stands on:** [MQTT 3.1.1 catalog](../../standard/mqtt311/catalog.md)

The base document is OASIS MQTT 3.1.1, 29 October 2014. Its data representations, control packet layouts, sessions, QoS delivery, retry, ordering and topic matching define this protocol profile. MQTT 5.0, MQTT-SN and transport bindings other than an ordered reliable byte stream are outside this profile. The catalog inventories numbered requirements; clauses also contain unnumbered requirements and optional choices.
