Native mesh aggregation contracts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The existing mesh HT/VHT profiles keep local A-MSDU formation disabled by default. Enable it with ``mac.hcf.originatorMacDataService.msduAggregationPolicy.typename = "BasicMsduAggregationPolicy"``. The policy's minimum count/length and user size constraints still apply; a grouping that fails negotiated transport admission falls back to a plain MSDU instead of silently reducing that grouping below its policy thresholds. Received standalone A-MSDU support does not depend on enabling this local source policy.

Custom ``IMeshForwarding`` providers must implement ``finalizeSourceFrame(Packet *)`` and ``isSourceActive() const``. Finalization borrows a committed forwarding unit and allocates its mesh identity only when the local pending-source marker is present. A preview consumes none, one newly formed A-MSDU consumes one value, and committed transit/retry units retain their identities. The active-state query must use the source owner's lifecycle state, including withdrawal during stop/crash.

Custom ``IMeshDataMac`` providers must implement ``discardPendingMeshSources()`` through their queue/lifetime owner. Remove only uncommitted local sources, invalidate any reversible source preview and preserve committed, transit and on-air units. Retire those entries during isolated source-owner stop/crash and isolated provider removal while the MAC is alive, so a later restart cannot revive them. Whole-subtree deletion must not call already destroyed sibling modules. Missing source owners make pending sources unavailable; already committed units need no allocator. Do not silently return from a down finalizer and send a placeholder identity.

Custom ``IMeshLinkMetric`` providers must implement ``resetAggregation(MacAddress)``. This resets the payload aggregation estimate alone. Whole-peer/PHY-tuple reset still clears both aggregation and error estimates. ``meshPayloadTransmitted`` is a completed on-air PPDU fact, distinct from ``meshDataAttemptCompleted`` ACK/timeout outcomes; subscribing to both must not count the payload again on ACK.

``QoSContext`` has an optional, immutable ``prepareNormalAckData`` argument defaulting to false. HT/VHT mesh HCF enables it to preview and admit Normal-Ack forwarding units before queue extraction and identity commitment. Existing nonmesh contexts retain their default path. The direct originator extraction API still uses the same source finalization operation for its other consumers.

``Ieee80211MeshAggregationTag`` is local, nonserialized metadata. Its payload count is reconstructed from complete validated receive bytes before transit requeue. Its initial MPDU length is written once on the original by HCF after actual transmission completion, including MAC header and FCS but excluding delimiter/PHY padding. Receive reconstruction starts that evidence as unknown. A committed unit or Retry bit alone does not justify a positive-TXOP retry exception.

Generic raw four-address A-MSDU has insufficient role context to distinguish Basic/WDS from Mesh at radio capture. The Wi-Fi dissector retains that body opaquely while preserving its complete MAC/FCS interval. Explicit receiving MeshMac context selects native mesh traversal afterward. Ordinary Basic two-/three-address display and Basic deaggregation are unchanged; detailed raw WDS display requires explicit context.
